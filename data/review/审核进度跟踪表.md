## 四、更新规则（谁、什么时候、改哪列）

| 时机 | 谁 | 改什么 |
|---|---|---|
| 某人开始复核某条 | A 或 B 本人 | 该行 `A 复核`/`B 复核` 改为 `进行中` |
| 某人完成某条（结论见其副本） | A 或 B 本人 | 该行改为 `通过` / `需修改` / `无法判断`（与其副本一致） |
| A、B 全部交回某条 | 数据维护者 | `一致性` 改为 `同意` / `分歧`；分歧行 `仲裁` 改 `待仲裁` |
| 仲裁完成 | 仲裁者 | `仲裁` 改为 `通过` / `修改后通过` / `退回`；`最终状态` 改 `待仲裁` → 按结果更新 |
| 满足操作指南第 8 节**全部条件** | 数据维护者 | 该行 `最终状态` 改为 `已人工复核` |
| 任何状态变化后 | 数据维护者 | 同步更新"当前进展摘要" |

**红线**：`最终状态` 只有在全部真人条件满足后才能改 `已人工复核`；AI 只允许按真人结论抄录状态，不允许替真人判断。
