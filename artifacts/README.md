# 原始证据目录

`artifacts/` 只保存可复算的命令输出、实验原始结果和验收证据，不存放业务代码、
虚拟环境、缓存、截图替代品或任何 API Key。

## 命名与归档

- 每项证据使用独立子目录，名称包含成员、任务和绝对日期。
- 子目录必须有 `README.md`，列明代码版本、文件用途、完整输出位置和已知局限。
- 原始日志生成后不覆盖；需要重跑时新增带序号的文件，并在子目录索引说明原因。
- 汇总结论放在 `docs/验收记录_*.md`，原始输出留在本目录，避免把长日志塞入人读文档。
- 机器初标、离线诊断和真实人工/模型结果必须在目录名或索引中明确区分。
