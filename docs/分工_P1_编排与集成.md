## 五、你要守住的接口（对外唯一入口）

```python
# orchestrator.py
def run(岗位: str, 答题记录: list, question: str) -> dict:
    """
    返回最终通过审核的培训内容 + 全过程明细，供 app.py 展示。
    建议返回结构：
    {
      "画像": {...},              # P3 build_profile 输出
      "知识列表": [...],           # P2 search_knowledge 输出
      "培训内容": {...},           # P3 generate_content 输出（最终版）
      "审核明细": {...},           # P4 review_content 输出
      "重试次数": 1,
      "学习路径": [...],           # 供画图谱
      "协同日志": [...]            # 供过程可视化
    }
    """
```

`app.py` 只调这一个函数，其余都藏在 orchestrator 里。

## 六、踩坑提示（vibe coding 专用）

- **一次只让 AI 写一小块。** 别说「写整个 orchestrator」，说「写一个函数，输入 4 个 stub 函数，按顺序调用并返回合并结果」。
- **锁住能跑的代码。** 骨架跑通后，让 AI 改任何东西都加一句「下面这段已能正常工作，请勿改动，只新增」。
- **Streamlit 会整页重跑。** 用 `st.session_state` 存中间结果，避免每次点按钮都重新调 API（慢又费钱）。
- **不要暴露公网。** Streamlit 默认无鉴权，只在本地 Demo，别挂到服务器公网。
- **你是接口的唯一裁判。** 有人说「我想改一下输出格式」，先想清楚会不会连带影响下游，改了立刻同步全组并更新 `接口约定.md`。
