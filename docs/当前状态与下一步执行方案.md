## 一、项目现在已经到哪里

当前项目不是“只有 stub 的骨架”，已经具备以下实现：

- 公共契约：`contracts.py` 校验知识、画像和培训内容。
- 知识数据：`data/knowledge.json` 含 39 条“已验证”知识，均有来源和来源定位。
- 检索：ChromaDB + 中文字符 n-gram 哈希向量；未覆盖问题返回空列表。
- 画像：覆盖数控机床操作工、CNC 编程员、质检员，支持岗位先验、连续答题更新和学习路径。
- 生成：支持定制讲义、实操指南、分阶测试题；事实必须携带本次检索到的知识 ID。
- 审核：L1 规则检查、确定性 L2 知识锚定、可选 LLM L2 和 L3 异构投票路径。
- 编排：最多两次重新生成，终态为“通过 / 需人工复核 / 失败”，不会在重试耗尽后自动通过。
- 界面：可展示画像、来源、断言核查、迭代历史、内容诊断、学习路径和协同日志。
- 测试：仓库包含离线确定性 pytest、Streamlit UI 测试和三场景命令行演示。
- 评测初稿：`qa_test_set.json` 有 52 条案例，但全部仍是“机器初标，待人工双人复核”。
- 人工复核准备：已有双人复核规范、标准库 CSV 导出器、12 条空白试标表和结构校验测试；尚无任何人工 A/B 结论或仲裁结论。

2026-07-28 已在当前项目 `venv` 中完成 P1 自检：新增复核测试 5 项通过，全量离线测试 44 项通过并保留 1 条现有 ChromaDB 弃用警告。该结果不是 P2 的干净环境复现证据；P2 仍须在自己的 Windows 环境独立执行并保存完整输出。
