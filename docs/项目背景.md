# 项目背景（vibe coding 时贴给 AI 用）

> 每次开新对话让 AI 写代码前，把这份背景贴进去，再说你要做的具体任务。
> 详细研究方案见根目录 `智策育训_项目研究方案.md`。

## 是什么

**智策育训**——制造业个性化培训内容自动生成平台，兴智杯参赛项目（上海云之脑命题：领域知识个性化生成与多智能体协同决策系统）。

架构 = **1 Orchestrator + 4 Agent**：
1. 知识检索 Agent — 从制造业知识库检索相关知识（带来源）
2. 画像 Agent — 根据岗位+答题记录算出技能掌握度
3. 内容生成 Agent — 按画像+知识生成定制教程/实操指南/阶梯项目
4. 三层审核 Agent — 规则引擎 + 知识锚定 + 三模型异构投票，把幻觉率压到 5% 以下

## 解决什么痛点

制造业培训三大痛点：培训周期长、缺个性化、大模型幻觉。

## 技术栈（已锁定，别改）

- 语言：Python
- 界面：Streamlit（不写 HTML/CSS/JS）
- 向量库：ChromaDB（本地）
- 知识图谱：NetworkX 或纯 JSON
- 大模型：调 3 家不同厂商 API（DeepSeek/通义/Kimi/GLM/豆包 任选 3），构成三模型异构投票
- 编排：纯 Python 函数
- **不训练模型，不用 LangGraph/Neo4j**

## 团队与写代码方式

4 人小组，编码水平有限，靠 AI 写代码。所以要 AI：
- 用最简单能跑通的写法，不引入额外的库
- 一次只写一个小函数，附可直接运行的示例
- 写完用大白话解释每一步

## 评分维度（各 20 分）

技术创新性 / 系统完整性 / 个性化效果。**个性化和评估闭环是主要夺分点。**

## 分工

产品架构仍是 1 Orchestrator + 4 Agent，但**产品模块不等于人员分工**。4 人不再长期分别承包编排、检索、生成、审核，而是按阶段共同完成一条可运行的纵向链路：

1. 范围与契约
2. 假数据骨架
3. 首条真实链路
4. 审核与反馈闭环
5. 扩展与对比实验
6. 评测与体验
7. 冻结与提交

每阶段 4 人同时领取不同交付物，并由另一名成员交叉验收。现行安排见 `阶段制分工与互验计划.md`，模块接口见 `接口约定.md`。`分工_P1_*` 至 `分工_P4_*` 只作为模块技术参考，不代表固定人员职责。
