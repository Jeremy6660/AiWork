# 项目背景（vibe coding 时贴给 AI 用）

> 每次开新对话让 AI 写代码前，把这份背景贴进去，再说你要做的具体任务。
> 详细研究方案见 `docs/项目研究方案.md`。

## 是什么

**智策育训**——制造业个性化培训内容自动生成平台，兴智杯参赛项目（上海云之脑命题：领域知识个性化生成与多智能体协同决策系统）。

架构 = **1 Orchestrator + 4 Agent**：
1. 知识检索 Agent — 从制造业知识库检索相关知识（带来源）
2. 画像 Agent — 根据岗位+答题记录算出技能掌握度
3. 内容生成 Agent — 按画像+知识生成定制讲义/实操指南/分阶测试题
4. 三层审核 Agent — 确定性规则 + 逐条知识锚定 + 可选异构模型投票

当前已完成三个稳定岗位的离线确定性闭环；焊接、工业互联网和工业 AI 只保留实验画像，相关知识完成来源复核前不进入正式索引。真实 DeepSeek 生成、Qwen/GLM 异构投票取决于外部 Key 和操作者显式确认。幻觉率等竞赛指标只能在人工双人复核的评测集上报告，机器初标管线结果不是正式成绩。

截至 2026-08-05，离线门禁为 68 项测试和三场景通过；跨领域拒答、L3 状态区分与证据哈希问题已经修复并提交。当前仍缺真人双人复核、两项独立互验、经确认的真实模型调用，以及修复后版本一致的 P4 新证据包与独立复验，详见 `当前状态与下一步执行方案.md`。

## 解决什么痛点

制造业培训三大痛点：培训周期长、缺个性化、大模型幻觉。

## 技术栈（已锁定，别改）

- 语言：Python
- 界面：Streamlit（不写 HTML/CSS/JS）
- 向量库：ChromaDB（本地）
- 知识图谱：NetworkX 或纯 JSON
- 大模型：当前适配 DeepSeek/Qwen/GLM；三模型真实异构投票需配置对应外部 Key
- 编排：纯 Python 函数
- **不训练模型，不用 LangGraph/Neo4j**

## 团队与写代码方式

4 人小组，编码水平有限，靠 AI 写代码。所以要 AI：
- 用最简单能跑通的写法，不引入额外的库
- 一次只写一个小函数，附可直接运行的示例
- 写完用大白话解释每一步

## 评分维度（以比赛原始方案为准）

- 作品完整性：30 分
- 技术创新性：25 分
- 用户体验：15 分
- 实用价值：30 分

个性化适配、动态闭环和可量化指标分布在完整性、用户体验与实用价值中，仍是主要夺分点，但不是独立的“20 分”评分项。

## 分工

产品架构仍是 1 Orchestrator + 4 Agent，但**产品模块不等于人员分工**。4 人不再长期分别承包编排、检索、生成、审核，而是按阶段共同完成一条可运行的纵向链路：

1. 范围与契约
2. 假数据骨架
3. 首条真实链路
4. 审核与反馈闭环
5. 扩展与对比实验
6. 评测与体验
7. 冻结与提交

每阶段 4 人同时领取不同交付物，并由另一名成员交叉验收。P1–P4 只是四名成员编号，不再对应四个固定领域。总安排见 `阶段制分工与互验计划.md`，每人逐阶段任务见 `分工_P1_*` 至 `分工_P4_*`，模块接口见 `接口约定.md`。
