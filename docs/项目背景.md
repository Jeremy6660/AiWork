# 项目背景（vibe coding 时贴给 AI 用）

> 每次开新对话让 AI 写代码前，把这份背景贴进去，再说你要做的具体任务。
> 详细研究方案见 `docs/项目研究方案.md`。

## 是什么

**智策育训**——制造业个性化培训内容自动生成平台，兴智杯参赛项目（上海云之脑命题：领域知识个性化生成与多智能体协同决策系统）。

架构 = **1 Orchestrator + 4 Agent**：
1. 知识检索 Agent — 从制造业知识库检索相关知识（带来源）
2. 画像 Agent — 根据岗位+答题记录算出技能掌握度
3. 内容生成 Agent — 按画像+知识生成定制讲义/实操指南/分阶测试题
4. 三层审核 Agent — 确定性规则 + 逐条知识锚定 + 可选异构模型投票

当前已完成离线确定性闭环；真实 DeepSeek 生成、Qwen/GLM 异构投票取决于外部 Key。幻觉率等竞赛指标只能在人工双人复核的评测集上报告，机器初标管线结果不是正式成绩。

## 解决什么痛点

制造业培训三大痛点：培训周期长、缺个性化、大模型幻觉。

## 技术栈（已锁定，别改）

- 语言：Python
- 界面：Streamlit（不写 HTML/CSS/JS）
- 向量库：ChromaDB（本地）
- 知识图谱：NetworkX 或纯 JSON
- 大模型：当前适配 DeepSeek/Qwen/GLM；三模型真实异构投票需配置对应外部 Key
- 编排：纯 Python 函数
- **不训练模型，不用 LangGraph/Neo4j**

## 团队与写代码方式

4 人小组，编码水平有限，靠 AI 写代码。所以要 AI：
- 用最简单能跑通的写法，不引入额外的库
- 一次只写一个小函数，附可直接运行的示例
- 写完用大白话解释每一步

## 评分维度（以比赛原始方案为准）

- 作品完整性：30 分
- 技术创新性：25 分
- 用户体验：15 分
- 实用价值：30 分

个性化适配、动态闭环和可量化指标分布在完整性、用户体验与实用价值中，仍是主要夺分点，但不是独立的“20 分”评分项。

## 分工

- P1：Orchestrator + 集成 + Streamlit 界面 + Demo 视频
- P2：数据收集清洗 + ChromaDB + 知识图谱 + 检索 Agent
- P3：画像（岗位→技能掌握度）+ 内容生成 Agent
- P4：三层审核 + 幻觉率评测 + 效果评估闭环

模块间接口见 `接口约定.md`。
