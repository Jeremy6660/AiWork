1. `test_run.py` 在本机存在 Key 时可能隐式尝试真实调用；

稳定范围现为数控机床操作工、CNC 编程员和质检员。焊接、工业互联网、
工业 AI 画像保留为实验能力，主界面不展示。2026-07-30 新增的 9 条知识均
改为“待人工核验”，不进入正式 ChromaDB。

## 4. smoke 门禁

零费用命令：

```powershell
python scripts/smoke_llm.py --provider deepseek --scenario generate
```

实际输出显示本机已配置 Key，但预计调用次数为 0，并以
`[DRY-RUN] 未发起任何网络请求` 结束。脱敏输出见
`artifacts/p3_smoke_gate_20260730/`。

真实调用命令仅供另行确认：

```powershell
python scripts/smoke_llm.py --provider deepseek --scenario generate --execute
```

即使提供 `--execute`，仍需操作者在终端输入 `EXECUTE`。本轮未执行，不能
声称真实 DeepSeek 生成或真实三模型投票已经完成。
