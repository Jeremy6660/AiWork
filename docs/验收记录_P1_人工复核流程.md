## 4. 首次执行失败记录

首次直接运行 `.\venv\Scripts\Activate.ps1` 时，本机 PowerShell 执行策略阻止脚本：

```text
PSSecurityException：在此系统上禁止运行脚本
```

由于该次激活失败，随后命令误用了系统 Python：

```text
C:\Program Files\Python313\python.exe: No module named pytest
```

该次结果不计为通过。修复方式是在当前 PowerShell 进程内临时执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\venv\Scripts\Activate.ps1
```

随后打印 `sys.executable`，确认指向项目 venv，再重新导出和测试。未修改机器级或用户级执行策略。
