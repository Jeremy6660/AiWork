## 三、离线与密钥保护

所有业务验收命令均在同一个已激活的 venv 中显式设置：

```powershell
$env:PYTHON_DOTENV_DISABLED = "1"
$env:GENERATION_MODE = "offline"
$env:ENABLE_LLM_REVIEW = "0"
$env:ENABLE_L3_VOTING = "0"
$env:ALLOW_OFFLINE_FALLBACK = "1"
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
```

`PYTHON_DOTENV_DISABLED=1` 阻止 `python-dotenv` 打开 `.env`。本次没有运行真实 API，
没有读取、打印、记录或提交任何 API Key。
