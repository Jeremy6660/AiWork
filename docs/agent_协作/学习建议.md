## 当前项目卡点（团队应优先搞懂的事）

- **最大卡点不是技术，而是流程**：12 条人工双人试标 + 独立互验需要真人手动完成，AI 只能准备材料，不能代填结论。团队应想办法推进真人执行，而非继续加代码。
- **理解"离线测试通过 ≠ 阶段通过"**：E1 明确要求人工复核、独立互验、真实模型调用，缺一不可；不要仅凭 pytest 全绿就宣称完成。
- **安全拒答是制造业领域红线**：宁可多拒答，不能对跨领域问题错误生成培训内容。
- **证据要能复现**：任何交付都要保证他人 checkout 声明代码版本后能跑出同样结论，且不覆盖原始证据。
