1. **学会诊断 venv 环境损坏**：本次 pytest 报 `ModuleNotFoundError: No module named 'pydantic_core._pydantic_core'`。要知道这不是代码 bug，而是 `site-packages` 里 C 扩展二进制 `.pyd` 缺失。排查路径：看 `lib/site-packages/<包>/` 是否只有 `__init__.py`、没有编译后二进制；用 `venv\Scripts\python.exe -c "import <包>"` 复验；修复用 `pip install --force-reinstall --no-deps <包>==<版本号>`。
2. **理解"离线确定性验收"红线**：pytest 必须全程离线，真实模型调用只能走 `scripts/smoke_llm.py --execute` 且需操作者显式确认；机器初标（`--include-draft` 的 52 条 QA）永远是"非正式"，不升级为竞赛指标。
