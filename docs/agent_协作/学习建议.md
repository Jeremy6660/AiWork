## 今日学习重点

1. **学会区分"代码已修好"与"证据已提交"**：git 工作区里 12 个文件是 `M`（Modified 未提交），所以"修复存在"≠"有提交号可复现"。练习 `git status`、`git add`、`git commit`，理解 E1 要求"提交号一致的证据包"为什么要先提交再验收。
2. **再次确认人工复核红线**：`data/review/qa_pilot_12_review.csv` 实测 13 个人工列仍全部 0/12。**AI 只能准备空白表、校验结构，绝不能代填 A/B 结论或"已复核"状态**。两名真人独立标注 + 第三名真人仲裁后，才允许改"标注状态"。
3. **理解本次 pytest 的 5 个 error 是环境而非代码**：本宿主 cron shell 设了 `TEMP=/tmp`（MSYS 路径），Windows pytest 的 `tmp_path` 临时目录用例在此不可写，报 `PermissionError`/`FileNotFoundError`。用这条经验：**同一条命令在不同 shell（PowerShell / git-bash / cron 宿主）可能有不同结果**，判定"代码失败"前先确认是不是环境差异，且用 `PYTHONPATH=` 清掉宿主注入的路径再测。
