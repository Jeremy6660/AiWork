## 1. VS Code 安装与配置

### 1.1 下载安装

1. 打开 https://code.visualstudio.com/
2. 点 **Download for Windows**，下载 `.exe` 安装包
3. 双击运行，安装过程**这两项必须勾选**：

> ☑ **将 "通过 Code 打开" 操作添加到 Windows 资源管理器文件上下文菜单**
> ☑ **将 "通过 Code 打开" 操作添加到 Windows 资源管理器目录上下文菜单**

其余选项保持默认，一路下一步即可。

> 🍎 macOS：下载 `.zip` 解压后拖进「应用程序」，然后 `Cmd+Shift+P` → 搜 `shell command` → 选 "Install 'code' command in PATH"。

### 1.2 验证安装

打开终端（Win 键 → 输 `cmd` 回车），输入：

```bash
code --version
```

能输出版本号说明装好了。

### 1.3 推荐基础设置

打开 VS Code → 左下角齿轮 → 设置（或 `Ctrl+,`），搜以下项目修改：

| 设置项 | 建议值 | 作用 |
|---|---|---|
| Files: Auto Save | `afterDelay`（1000ms） | 自动保存，防止丢代码 |
| Editor: Font Size | 16 | 看着舒服 |
| Editor: Tab Size | 4 | Python 用 4 空格缩进（PEP8） |
| Editor: Render Whitespace | `all` | 能看到空格和 Tab 的区别 |
| Files: Encoding | `utf8` | 中文不乱码 |

## 2. AI 编程助手安装

本项目靠 AI 辅助写代码（vibe coding），每人至少装一个。**全组统一用 Claude Code**。

### 2.1 第 1 步：安装 Node.js（Claude Code 的前提）

Claude Code 是用 Node.js 写的，必须先装 Node.js ≥ 18。

**Windows：**

1. 打开 https://nodejs.org
2. 下载 **LTS（长期支持版）**，比如 `20.x.x LTS` 或 `22.x.x LTS`
3. 双击 `.msi` 安装包，一路下一步即可
4. 装完**重启终端**，验证：

```bash
node --version    # 比如 v22.12.0
npm --version     # 比如 10.9.0
```

> 🍎 macOS：建议用 Homebrew 装—— `brew install node`。

### 2.2 第 2 步：安装 Claude Code

打开终端（Win+R → 输 `cmd` 回车），输入：

```bash
npm install -g @anthropic-ai/claude-code
```

> 如果遇到权限错误，Windows 上以管理员身份运行终端再执行。

验证：

```bash
claude --version
```

### 2.3 第 3 步：首次启动

```bash
cd %USERPROFILE%\Documents\AiWork    # 进入项目目录（按你们实际路径改）
claude                                # 启动 Claude Code
```

首次启动会弹浏览器，登录 Anthropic 账号（找组长要账号或 API Key）。后续使用见[第 7 节](#7-claude-code-常用命令)。

### 2.4 备选：OpenAI Codex CLI

Claude Code 额度用完时的备选，装法一样：

```bash
npm install -g @openai/codex
```

> **建议**：主力用 Claude Code，因为它会自动读取项目 `CLAUDE.md` 规则文件，按项目约束写代码。Codex 不会读这个文件。

## 3. Git 安装与基本操作

### 3.1 安装 Git for Windows

1. 打开 https://git-scm.com/download/win
2. 下载 **64-bit Git for Windows Setup**
3. 双击安装，选项太多不要慌——**全部默认**一路下一步即可
4. 装完验证：

```bash
git --version
```

> 🍎 macOS 自带 git，不用装。

### 3.2 首次配置（每个人都要做）

```bash
git config --global user.name "你的名字（拼音或中文）"
git config --global user.email "你的邮箱"
```

### 3.3 日常操作速查（每天都会用）

```bash
# 克隆项目（第一次）
git clone <仓库地址>

# 每天写代码的标准流程（5 步）：
git pull                        # 1. 拉最新代码 ← 写代码前必须！
git status                      # 2. 看看自己改了哪些文件
git add .                       # 3. 把所有改动加入暂存区
git commit -m "feat: 加了检索 Agent 的 stub"  # 4. 提交（写清楚改了啥）
git push                        # 5. 推到远程仓库
```

### 3.4 分支操作（必学）

项目分支策略：

```
main ← 永远可运行
  ├── p1-xxx    ← P1（组长）
  ├── p2-xxx    ← P2 同学
  ├── p3-xxx    ← P3 同学
  └── p4-xxx    ← P4 同学
```

```bash
git branch                        # 看自己在哪个分支
git checkout -b p2-add-chromadb   # 新建分支并切过去
git checkout main                 # 切换到 main 分支
```

**每个人在自己的分支上写，写完再合到 main。**

### 3.5 常见翻车 & 救援

| 情况 | 怎么救 |
|---|---|
| 忘了 pull 就改了代码，push 被拒 | `git pull --rebase` 再 push |
| commit 信息写错了 | `git commit --amend -m "新信息"` |
| 改了不该改的文件想撤销 | `git checkout -- 文件名` |
| 想临时藏一下改动 | `git stash` / 恢复 `git stash pop` |
| push 弹窗要求登录 | 组长会在群里发 token 或 SSH 配置方法 |

### 3.6 .gitignore（项目已配好，不用动）

确保项目根目录 `.gitignore` 里有这些内容（**绝对不能提交的东西**）：

```gitignore
.env                    # API 密钥，死也不能提交！
__pycache__/
*.pyc
.venv/
chroma_db/              # 本地向量库数据
```

## 5. Python 安装与项目环境搭建

### 5.1 安装 Python 3.12

**Windows：**

1. 打开 https://www.python.org/downloads/
2. 下载 **Python 3.12.x**（Windows installer 64-bit）
3. 双击 `.exe`，**第一个界面必须勾选**：

> ☑ **Add python.exe to PATH** ← 这是最关键的一步！忘记勾选后面全是坑

4. 然后点 "Install Now"，等装完
5. **重启终端**，验证：

```bash
python --version    # 期望：Python 3.12.x
pip --version       # 期望：pip 24.x
```

> 🍎 macOS：`brew install python@3.12`

### 5.2 创建虚拟环境（每个项目独立隔离）

打开终端，cd 到项目目录：

```bash
cd %USERPROFILE%\Documents\AiWork
```

> 上面路径改成你实际放项目的路径。

```bash
# 创建虚拟环境（只需一次）
python -m venv .venv
```

创建完后项目目录下会多一个 `.venv` 文件夹（已加入 `.gitignore`，不会提交）。

### 5.3 激活虚拟环境

**这是最容易忘的一步——每次新开终端都要激活！**

**Windows（CMD）：**
```bash
.venv\Scripts\activate
```

**Windows（PowerShell）：**
```bash
.venv\Scripts\Activate.ps1
```

> 如果 PowerShell 报红字 "无法加载文件..."，先执行这一行再激活：
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

**怎么判断激活成功了？** 终端最左边会显示 `(.venv)`：

```
(.venv) C:\Users\xxx\Documents\AiWork>
```

> 🍎 macOS：`source .venv/bin/activate`

### 5.4 安装项目依赖

确认虚拟环境已激活（左边有 `(.venv)`），然后：

```bash
pip install -r requirements.txt
```

等它装完，没报错就行。

> 以后如果装了新库，更新 requirements.txt：
> ```bash
> pip freeze > requirements.txt
> ```

### 5.5 VS Code 里选 Python 解释器

1. 用 VS Code 打开项目文件夹
2. 按 `Ctrl+Shift+P`
3. 搜 **"Python: Select Interpreter"**
4. 选那个路径里带 `.venv` 的（比如 `Python 3.12.x ('.venv': venv)`）

选对之后，VS Code 里新开的终端会自动激活虚拟环境。

## 6. 大模型 API 申请与使用

本项目要调 **3 家不同厂商的大模型 API**（用于三模型异构投票）。

### 6.1 通用申请流程（每家大差不差）

1. 打开平台网站，注册账号（用手机号就行）
2. 进「控制台」或「API Keys」页面
3. 点「创建 API Key」→ 复制下来（**只显示一次，立刻保存！**）
4. 把 Key 写到项目 `.env` 文件（见 6.3）

### 6.2 各平台入口一览

| 厂商 | 申请地址 | 模型名 | 备注 |
|---|---|---|---|
| **DeepSeek** | https://platform.deepseek.com/ | `deepseek-chat` | 性价比最高，代码能力强，首充送额度 |
| **通义千问** | https://dashscope.aliyun.com/ | `qwen-turbo` / `qwen-plus` | 阿里云，新用户有免费额度 |
| **Kimi（月之暗面）** | https://platform.moonshot.cn/ | `moonshot-v1-8k` | 超长上下文 |
| **智谱 GLM** | https://open.bigmodel.cn/ | `glm-4-flash` | 清华系，有免费额度 |
| **豆包（字节）** | https://console.volcengine.com/ark | `doubao-lite` | 字节系，需实名 |

> **本项目目标**：从上面任选 3 家申请即可。组长可能提前申请好并把 Key 发群里。

### 6.3 .env 文件怎么写

项目根目录新建 `.env` 文件（右键 → 新建文本文件 → 改名 `.env`）：

```bash
# .env —— 密钥只放这！绝对不提交 Git！
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
MOONSHOT_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

代码里用 `os.getenv()` 读，**绝不硬编码 Key**：

```python
import os
from dotenv import load_dotenv

load_dotenv()                          # 加载 .env
api_key = os.getenv("DEEPSEEK_API_KEY")  # 只读环境变量，不写死
```

### 6.4 Python 调用示例（各平台写法统一）

这些平台都兼容 OpenAI 的 SDK 格式，只是 `base_url` 和 `model` 不同：

```python
from openai import OpenAI

# DeepSeek 示例
client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "简述数控机床的日常维护要点"}]
)
print(response.choices[0].message.content)
```

各厂商的 `base_url` 对照：

| 厂商 | base_url |
|---|---|
| DeepSeek | `https://api.deepseek.com/v1` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Kimi | `https://api.moonshot.cn/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| 豆包 | `https://ark.cn-beijing.volces.com/api/v3` |

> P1 写好了统一调用函数后，大家不用记这些，直接调函数就行。

## 7. Claude Code 常用命令

在 Claude Code 终端里，输入 `/` 开头的命令。

### 7.1 日常命令速查

| 命令 | 作用 |
|---|---|
| `/help` | 列出所有可用命令 |
| `/clear` | 清空对话，重新开始 |
| `/compact` | 对话太长变慢时，压缩上下文 |
| `/cost` | 看本次对话花了多少 token |
| `/model` | 切换模型（opus / sonnet / haiku） |
| `/status` | 查看当前会话状态 |

### 7.2 权限模式切换

| 模式 | 怎么进 | 说明 |
|---|---|---|
| **普通模式**（默认） | 启动就是 | 每次操作弹确认框 |
| **自动模式** | 对 Claude 说 "auto-approve my commands" | 常规操作自动放行，危险操作仍需确认 |
| **计划模式** | `/plan` 或 `/enter-plan-mode` | AI 只思考不动手，方案等你确认再执行 |

### 7.3 本项目里怎么用 Claude Code

项目根目录放了 `CLAUDE.md` 规则文件，Claude Code 每次启动自动读取。

**新开对话写代码的标准流程：**

1. 打开终端，cd 到项目目录
2. 敲 `claude` 启动
3. 把需求说清楚，比如："帮我在 `agents/retrieval.py` 里写一个检索函数，输入岗位名+关键字，返回 top-5 最相关的文档片段"
4. Claude Code 会读 `CLAUDE.md` → 知道只能用 Python、不引入重框架 → 按项目约束写代码
5. 它写完你审查 → 确认无误 → 在 VS Code 里测试跑通

### 7.4 一个实用技巧：贴背景上下文

每次新开对话，如果涉及跨模块修改，可以这样说：

> "请先读 `docs/项目背景.md` 和 `docs/接口约定.md`，然后帮我 xxx"

这样 Claude 就能理解整个项目的背景和接口约束。
