## 四、核心设计思路（先理解再写代码）

### 4.1 冷启动怎么解

DKT 需要大量学员答题数据——你们没有。但官方要求做画像，解法：

**方案：岗位能力模型（先验）+ 少量交互（贝叶斯更新）**

1. **岗位能力模型 `skill_ontology.json`**：手工定义 3-5 个制造业常见岗位，每个岗位列 5-8 个核心技能，每个技能标「难度层级（入门/基础/进阶/专家）」+ 「先修关系」。
   示例：
   ```json
   {
     "数控机床操作工": {
       "核心技能": {
         "机床安全规范": {"难度": "入门", "先修": [], "初始先验": 0.85},
         "识图读图": {"难度": "基础", "先修": [], "初始先验": 0.60},
         "主轴转速计算": {"难度": "基础", "先修": ["识图读图"], "初始先验": 0.40},
         "刀具选择": {"难度": "进阶", "先修": ["识图读图", "主轴转速计算"], "初始先验": 0.30},
         "故障诊断": {"难度": "专家", "先修": ["刀具选择", "主轴转速计算"], "初始先验": 0.15},
         "G代码编程": {"难度": "进阶", "先修": ["识图读图"], "初始先验": 0.25}
       }
     }
   }
   ```
   每个技能的「初始先验」就是冷启动时的猜测值。一个新入职操作工，安全规范基本过关（0.85），故障诊断基本不会（0.15）。合理、好讲、不会被质疑「你怎么知道」。

2. **答题更新**：如果有答题记录，用最简单的贝叶斯更新每个技能的掌握度（答对→上升，答错→下降）。公式就是 `{新掌握度 = 旧掌握度 + 学习率 × (实际结果 - 旧掌握度)}`，AI 能帮你写，不用懂数学。

> **为什么这比纯 DKT 好**：DKT 无数据完全跑不动。岗位先验模型有工业心理学/胜任力模型背书，评委听起来更靠谱。

### 4.2 个性化路径怎么规划

依据 P2 的知识图谱（先修关系）+ 你的技能掌握度，做一个简单的贪心推荐：**选该岗位先修已满足、当前掌握度最低的技能，优先推荐对应培训内容**。输出是一个有序列表（这个人的学习路径），P1 拿去画图谱。

  - 如果 `答题记录` 有内容 → 用贝叶斯更新调整掌握度。

- [ ] `generate_content()` 接真实 LLM API：
  - 写一个详细的提示词：告诉模型「你是制造业培训师，以下是学员的当前技能水平（XX 技能 0.3 分）和可用的知识素材（3 条），请生成适合他水平的教程，只使用提供的素材，不自由发挥，并标注引用了哪条来源」。
  - 生成内容的难度要适配。掌握度低的技能 → 生成教程（入门型），掌握度中等的 → 生成实操指南（应用型），掌握度高的 → 生成阶梯项目（挑战型）。

## 六、接口约定（你的两个函数）

```python
# agents/profile.py
def build_profile(岗位: str, 答题记录: list) -> dict:
    """
    输入：岗位（如"数控机床操作工"）、答题记录（可为空列表）
    输出：{"岗位": str, "技能掌握度": {技能名: 0-1分数}}
    冷启动用岗位先验，有答题记录则更新
    """

# agents/generator.py
def generate_content(画像: dict, 知识列表: list, 修改建议: str = "") -> dict:
    """
    输入：画像(build_profile输出)、知识列表(search_knowledge输出)、修改建议(审核不通过时传入)
    输出：{"类型": "教程|实操指南|阶梯项目", "标题": str, "正文": str(Markdown), "引用来源": [str]}
    必须只依据传入的知识列表生成，禁用自由发挥。引用来源列表不能大于知识列表。
    """
```

> 注意 `generate_content` 我比接口约定多加了一个 `修改建议` 参数——审核不通过回炉重生成时用。和 P1 确认后同步改 `接口约定.md`。

## 七、踩坑提示

- **DKT 标签别强提。** 在没有真实学员数据的情况下硬说「我们用了 DKT」会被评委追问到穿帮。改说「基于岗位能力模型的个性化画像 + 交互式动态更新」，学术上站得住。
- **生成时锁定知识范围。** 告诉 LLM「下面是你唯一可用的知识素材，不要引用你训练数据中的任何信息」。这是防幻觉最重要的一步，也给 P4 的审核减轻负担。
- **提示词要存版本。** 提示词是你的核心资产，每次改都备份旧版。好的提示词和烂的提示词，生成质量天差地别。
- **别追求技能数量多。** 3 个岗位 × 6-8 个技能 = 18-24 个技能就够了。精比多重要，每个技能说清先修关系和难度。
- **个性化要可演示。** 评委看视频的时候，最直观的就是「同问题→不同水平→不同结果」。确保 3 组画像出来的东西肉眼可见不同。
