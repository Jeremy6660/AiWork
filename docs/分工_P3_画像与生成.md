# P3 阶段制任务书

> P3 现在只是成员编号，不再等于“画像与生成负责人”。
> P3 会随阶段轮换测试、编排、画像、界面、异构审核和稳定性任务。
> 总计划与阶段退出门槛以 `阶段制分工与互验计划.md` 为准。

## 当前执行

截至 2026-07-28，S0–S3 已完成最小实现，不再重做 stub。本轮 P3 负责真实模型 smoke test、安全降级和外部 Key 阻塞证据，由 P4 验收；同时须按 `docs/验收记录_P2_干净环境复现与离线基线.md` 独立复验 P2 的环境证据并填写“通过 / 不通过”。真实模型任务继续使用 `docs/当前状态与下一步执行方案.md` 的 P3 提示词。

## 三、各阶段怎样才算完成

### S0：接口测试样例

要做：

- 为检索、画像、生成、审核、评估和 orchestrator 各准备正常 JSON。
- 至少覆盖空问题、未知岗位、空检索、审核失败四类异常。
- 建统一验收记录模板。

通过标准：

- P4 能直接拿样例定义黄金场景。
- 样例字段与 `docs/接口约定.md` 完全一致。
- P3 验收 P2 的环境骨架：在本机执行检查命令并记录结果。

### S1：最小 orchestrator

要做：

- 按接口调用所有 stub。
- 使用一个共享状态 dict 保存画像、知识、内容、审核、评估和日志。
- 支持最多 2 次重试，并保留每次尝试的记录。

通过标准：

- P1 能通过固定开关触发一次失败后重试。
- 任何 Agent 返回异常时，日志能指出失败步骤。
- P3 验收 P1 的检索和画像 stub，确保 orchestrator 可直接导入。

### S2：岗位技能本体和画像

要做：

- 建数控机床操作工的 6–8 个技能、初始先验和先修关系。
- 答题记录为空时使用岗位先验。
- 有答题记录时用简单、可解释的规则更新掌握度。
- 准备低、中、高三组差异画像。

通过标准：

- P2 能复现三组画像，所有掌握度在 0–1。
- 相同答题记录得到稳定结果。
- 不宣称使用未经真实数据验证的复杂 DKT。
- P3 验收 P4 的生成：只使用传入知识，引用来源是检索来源的子集。

### S3：审核闭环界面

要做：

- 逐步展示 L1、L2、是否触发重生成和每次幻觉分数。
- 同屏展示修改前后正文和修改建议。
- 准备一个正常通过案例和一个故意植入错误的驳回案例。

通过标准：

- P4 能只看页面解释系统做出每个决策的原因。
- 页面不隐藏失败、降级或人工复核状态。
- P3 验收 P2 的闭环：重试次数受限，协同日志完整。

### S4：L3 三模型投票

要做：

- 为三家模型提供统一调用接口和统一 JSON 输出。
- 只有高风险内容才触发 L3。
- 实现 2/3 多数投票、单模型超时和双模型降级。
- 记录每次调用的模型、耗时、结果和触发原因。

通过标准：

- 人为让一家 API 失败，系统仍能返回明确审核状态。
- 未触发 L3 时不产生三家模型费用。
- P1 能使用固定样例重复测试投票逻辑。
- P3 验收 P1 的学习路径：三组画像产生可解释的不同路径。

### S5：稳定性、缓存和配置

要做：

- 处理 API 超时、空检索、无效岗位和模型非 JSON 返回。
- 用 `st.session_state` 或简单缓存避免页面重复调用 API。
- 记录模型调用次数、耗时和估算成本。
- 所有密钥只从 `.env` 读取。

通过标准：

- P2 能复现三类主要异常，页面不会直接显示堆栈。
- 重复点击不会无故重复产生全部 API 调用。
- P3 验收 P4 的演示材料：至少 2–3 组完整输入输出且时间可控。

### S6：技术与答辩材料

要做：

- 写清 1 Orchestrator + 4 Agent 架构和动态编排逻辑。
- 说明可溯源检索、差异化画像、分级审核和反馈闭环四个核心点。
- 主动写出数据规模、仿真验证和指标适用范围等局限。
- 准备常见追问及证据位置。

通过标准：

- P4 能根据材料完成一次模拟答辩。
- 每个创新点都指向实际代码、样例或评测证据。
- P3 验收 P2 的评测报告，随机抽数字可以追溯到原始记录。

## 四、P3 每日检查

- 是否用契约样例开发，而不是等待上游真实模块。
- 日志是否足以定位失败发生在哪一步。
- 异常处理是否给用户可理解的提示。
- 是否把半成品交给验收者实际运行。
- 验收别人的任务时是否保存命令和结果。

## 五、P3 不再长期负责

P3 不再永久承包画像、生成和个性化。即使某阶段负责 orchestrator 或 L3，也只是阶段任务；完成后必须通过文档、样例和互验让其他成员具备接手能力。
