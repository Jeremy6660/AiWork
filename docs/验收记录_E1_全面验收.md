- 真实 Qwen/GLM 异构投票也没有验收证据。

### 3.3 P4 尚无独立验收，证据版本不可按声明复现

- 未找到 P1 对 P4 的独立验收记录。
- P4 证据声明代码版本为 `01cb84e`，但该提交不包含 P4 脚本、文档或结果文件；
  这些文件首次出现在 `36c9bde9c0aa81834cd69b1f2bd9e1939ebfc2f1`。
- 因此按文档要求 checkout `01cb84e` 不能复现实验。

### 3.4 跨领域未覆盖问题会错误生成内容

- 输入“核电站操作规程”时，检索错误命中 `CNC-SAFE-001`，分数为 `0.2686`。
- Orchestrator 最终返回“通过”且生成了培训内容。
- 该结果违反未覆盖问题必须返回空检索并拒绝生成的契约，也是制造业安全边界缺陷。

### 3.5 L3 审核状态存在冲突

- P4 实验确实进入 L3 无可用供应商的阻塞分支，并返回“需人工复核”。
- 同一结果的 `审核明细.模型投票` 却为“未触发”，无法区分“低风险未触发”和
  “已升级但 0 个供应商可用”。

### 3.6 证据完整性问题

- P2 证据清单中的前 5 个 SHA-256 与当前文件不一致：
  `01_environment_setup_full.txt` 至 `05_boundary_sample_full.txt`。

  与 `artifacts/README.md` 的“重跑新增编号、不得覆盖原始日志”规则冲突。
